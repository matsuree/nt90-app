# UI・スタイル方針（ドラフト）

- 状態：ドラフト（議論中）
- 最終更新：2026-10-27
- 機能の仕様は [spec.md](./spec.md) を参照。印（【決定】【提案】【未決】）の意味も spec.md と同じ。

---

## 1. 前提

| 項目 | 内容 |
|---|---|
| 表示環境 | LINEアプリ内のWebビュー（LIFF、サイズ Full）。スマホの縦画面が中心 |
| 想定する利用者 | 18歳以上の流山市民すべて。スマホ操作に慣れていない人や高齢の人も含む |
| 利用シーン | リッチメニューやトークのリンクから開き、数十秒で宣言・報告して閉じる |

## 2. デザインの方針【提案】

1. **ひと目でわかる。** 1画面でやることは1つにする。メインのボタンは大きく、画面下の押しやすい位置に置く。
2. **文字は少なく、短く。** 長い文章は出さない。体言止めの短い表現にする（3.4）。【決定】
3. **読みやすい。** 本文は16px以上にする。色だけで情報を伝えない（文字やアイコンを添える）。
4. **親しみやすく、中立。** 業務アプリのような硬さを避けて、温かみのある見た目にする。政党・候補者を連想させる色やモチーフは使わない。

## 3. スタイル

### 3.1 色【決定】

背景は薄いベージュ、メインカラーは深緑にする。深緑はプロジェクトのロゴ（緑の投票箱）に合わせた色。

| 用途 | 色 | 備考 |
|---|---|---|
| 背景 | 薄いベージュ（例：#FAF6EE） | 画面全体 |
| カード | 白（#FFFFFF） | ベージュの上に載せて区切る |
| メインカラー | 深緑（例：#1F6F4A） | ボタン、強調。白い文字を載せても読みやすい濃さ |
| メインカラー（薄） | 薄い緑（例：#E6F2EA） | 選択中の項目、バッジ |
| 文字 | 濃い茶系のグレー（例：#2B2A27）。補足は #6B675F | 真っ黒を避けて、ベージュになじませる |
| 枠線 | #E7E0D2 | |
| エラー | #B42318 | |
| 完了・達成 | 黄色系（例：#E9A23B） | 宣言・報告が終わったときのお祝い表示 |

- 具体的な色の値は、実装時に画面で見ながら調整する。文字と背景の色の差は、読みやすさの基準（WCAG AA）を満たすようにする。
- LINE自体の緑（#06C755）とは明るさを変えて、LINEの公式画面と見分けられるようにする。
- ダークモードには対応しない（当面はライトのみ）。

### 3.2 文字【提案】

- 端末標準の日本語フォントを使う（iPhone はヒラギノ、Android は Noto Sans JP など）。
  - 今の雛形にある英字フォント（Geist）は外す。
  - Webフォントを読み込まないので、表示が速い。
- サイズの目安

| 用途 | サイズ |
|---|---|
| 本文 | 16px |
| 補足 | 14px |
| 見出し | 20〜24px |
| 大きな数字（残り日数・率・人数） | 32px以上 |

### 3.3 部品【決定】

- UI部品には **shadcn/ui** を使う。
  - 部品のコードはリポジトリにコピーして使う方式なので、色・角丸・サイズを自由に変えられる。
  - 標準のテーマのままだと業務アプリっぽくなるため、次のように調整する。
    - 背景をベージュにする
    - 角丸を大きめにする（12〜16px）
    - ボタンを大きめにする
    - 影は控えめにする
    - 余白を広めにとる
- 使う部品は少なくする。

| 部品 | shadcn/ui の部品 | 方針 |
|---|---|---|
| メインボタン | Button | 画面幅いっぱい、高さ52px前後、角丸大きめ。1画面に1つ |
| サブボタン | Button（outline / link） | 取り消しなどの控えめな操作に使う |
| カード | Card | 選挙回の情報や自分の状態をまとめる |
| バッジ | Badge | 「宣言済み」「投票済み」などの状態表示 |
| 確認 | Drawer（下から出るパネル） | 取り消しのときだけ出す。宣言・報告は1タップで完了させる |
| 通知 | Sonner（トースト） | 完了やエラーを短く知らせる |

### 3.4 言葉づかい【決定】

- 短く、わかりやすく。体言止めを基本にする。
- 「！」は使わない。

| 場面 | 文言 |
|---|---|
| 宣言ボタン | 投票宣言をする |
| 報告ボタン | 投票した |
| 宣言の取り消し | 宣言を取り消す |
| 報告の取り消し | 報告を取り消す |
| 投票区の変更 | 投票区を変更 |
| 宣言済みの状態 | 投票宣言済み |
| 投票済みの状態 | 投票済み |
| 宣言の完了 | 投票宣言完了 |
| 報告の完了 | 投票報告完了 |
| 市全体の人数 | 1,234人が投票宣言中／1,234人が投票済み |
| 残り日数 | 投票日まであと12日 |
| 受付期間外 | 宣言受付終了／報告受付終了 |
| 選挙がないとき | 次の選挙まで準備中 |

- 選挙の結果や候補者には一切触れない。

## 4. 画面構成

### 4.1 ナビゲーション【決定】

- 画面下にタブを置く：「ホーム」「ランキング」「マップ」
- フェーズ2から「ホーム」「ランキング」の2つのタブを出す（`app/(main)/layout.tsx`）。
- 「マップ」はフェーズ3で追加する。

### 4.2 画面一覧

| # | 画面 | フェーズ | 内容 |
|---|---|---|---|
| S1 | ホーム | 1 | 公開中の選挙回、自分の状態、市全体の人数、メインボタン（4.3） |
| S2 | 投票区の選択 | 1 | 投票所の一覧から選ぶ（spec 6.3）。初回の宣言・報告のときと、変更するときに開く |
| S3 | 完了 | 1 | 宣言・報告の完了表示。ホームに戻るボタン |
| S4 | 選挙がないとき | 1 | 「次の選挙まで準備中」 |
| S5 | エラー | 1 | 通信エラーやLIFFの初期化失敗。再読み込みボタン |
| S6 | ランキング | 2 | 3種類をタブで切り替え（spec 9.1） |
| S7 | マップ | 3 | Leaflet＋地理院タイル |
| S8 | このアプリについて | 1 | プロジェクトの紹介、[プライバシーポリシー](./privacy-policy.md)、データの出典表示 |

### 4.3 ホーム画面（S1）の状態ごとの表示【提案】

| 状態 | 主な表示 | メインボタン |
|---|---|---|
| 宣言の受付中・未宣言 | 選挙名、投票日まであと◯日、◯人が投票宣言中 | 投票宣言をする |
| 宣言の受付中・宣言済み | 「投票宣言済み」バッジ、自分の投票区 | 期日前投票の期間なら「投票した」。それ以外はなし |
| 投票報告の受付中・未報告 | 選挙名、◯人が投票済み | 投票した |
| 投票済み | 「投票済み」バッジ、お祝い表示 | なし（ランキングへのリンクはフェーズ2から） |
| 受付終了 | 宣言受付終了／報告受付終了 | なし |

- 宣言・報告の取り消しと投票区の変更は、メインボタンの下に小さなリンクで置く。

## 5. 実装メモ【決定】

- Tailwind CSS（v4）＋ shadcn/ui を使う。
- **見た目の調整は、ページごとに個別に書かない。** 共通の場所でまとめて行う。
  - 色・角丸・フォントなどのテーマ：`app/globals.css` の CSS 変数（shadcn/ui のテーマ変数）で定義する。
  - ボタンの大きさなど部品ごとの見た目：`components/ui/` の各部品で、標準の見た目そのものを調整する。
  - ページ側では、レイアウト（並べ方・余白）以外のスタイルを書かない。色の値をページに直接書くこともしない。
- shadcn/ui の部品は `components/ui/`、アプリ独自の部品は `components/` に置く。
- 画面幅は `max-w-md`（約448px）で中央寄せにする。タブレットやPCで開いても崩れないようにするため。
